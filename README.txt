موقع المفاجأة إلى نور ❤️

الملف الأساسي: index.html

النشر عبر GitHub Pages:
1. افتح المستودع الذي أنشأته على GitHub.
2. ارفع ملف index.html إلى الصفحة الرئيسية للمستودع (Add file > Upload files).
3. افتح Settings > Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع main والمجلد /(root)، ثم Save.
6. بعد ظهور رابط الموقع بصيغة https://اسمك.github.io/اسم-المستودع/ أرسله لي لأصنع لك باركود QR على شكل قلب يفتح المفاجأة.

ملاحظات:
- يبدأ العرض عند الضغط المطوّل على القلب الأحمر.
- الموسيقى مضمنة من رابط YouTube وتبدأ من 0:49، مع طلب إيقافها عند 2:09.
- قد تمنع بعض المتصفحات التشغيل التلقائي أو إخفاء مشغل YouTube؛ إذا لم يبدأ الصوت، اضغط على الصفحة مرة أخرى أو افتحها في المتصفح.
